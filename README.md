# RinoSaur Web 🦏

Public distribution space for the playable web versions of **RinoSaur**, developed by **RHYNUS Interactive Works**.

## Play

| Version | Status | Access |
|---|---|---|
| 2D / 2.5D | Current playable web reference | [Open the 2D version](https://rhynocerus.github.io/rinosaur-web/2d/) |
| 3D prototype | In active development | [Open the 3D status page](https://rhynocerus.github.io/rinosaur-web/3d/) |
| WebXR | Planned after the Web 3D slice | Coming later |

The 2D status page links to the current playable build while the public distribution is being prepared. The 3D page will become playable when the prototype passes its visual, interaction and performance checks.

## Source

The development source remains private while the project is being refined:

- [RinoSaur source repository](https://github.com/rhynocerus/rinosaur)
- [3D prototype branch](https://github.com/rhynocerus/rinosaur/tree/feat/prototype-3d)

## Project direction

RinoSaur is evolving through three controlled stages:

1. Stable 2.5D board-game foundation.
2. Real 3D board with materials, camera orbit, atmosphere and economy.
3. Separate WebXR/VR prototype after the Web 3D version is stable.
